# Stats 风扇曲线版

最终应用名为 **Stats**，安装位置是 `/Applications/Stats.app`。它保留 Stats 原有界面，并在“传感器”设置中加入温度自动风扇曲线；日常只需要打开这一个应用。

## 基础转速和温控曲线（851.3）

在 Stats → 设置 → 传感器 → 模块中设置：

1. 在“风扇转速范围”中，为每个风扇填写“基础转速”和“最高风扇转速”，按回车或离开输入框保存。
2. 开启“保持基础转速”，低温时也持续保持基础转速。例如基础 2200 RPM、最高 4000 RPM。
3. 同时开启“温度自动风扇曲线”，选择 Hottest CPU，填写开始提速温度及达到最高转速的温度。例如 55 °C 和 70 °C：55 °C 以下保持 2200 RPM；温度持续升高约 8 秒后，逐渐加速；62.5 °C 时目标为 3100 RPM；70 °C 及以上目标为 4000 RPM。实际风扇需要几秒跟上目标。
4. 这两个开关相互独立：只开基础转速可恒速运行；只开曲线则低温交还系统；同时开启则曲线从基础转速开始，降温后回到基础转速；两者关闭时交还 macOS。

- 本机风扇可设置范围为 1000–4900 RPM，最高转速不能低于基础转速。其他电脑按各风扇实际硬件范围限制，不支持强行超过硬件极限。
- 两个温度均可直接输入整数，开始温度支持 0–104 °C，最高转速温度支持 1–105 °C，后者须高于前者。
- 设置会保存，Stats 重新打开后恢复。睡眠或退出时交还系统，唤醒或重新打开后继续。需要开机持续生效时，请同时开启 Stats 的登录时启动。
- CPU 或 GPU 达到 95 °C 时，过热保护可突破自定义最高转速，使用硬件最高转速；低于 90 °C 解除保护。
- “记住手动转速”是旧的手动模式恢复选项，仅在上述两项规则都关闭时使用。在风扇弹出面板中直接手动调速会关闭两项规则，避免多个控制来源互相覆盖。
- 没有有效温度输入时，开启中的温控曲线会交还系统，不使用失效的温度维持低速。

## 风扇授权服务

风扇转速写入需要 macOS 管理员授权。授权服务以系统后台组件运行，不会出现在“应用程序”里，也不需要用户单独打开。当前这台 Mac 已安装该服务。

在其他 Mac 首次启用曲线时，Stats 会显示一次授权提示，临时调用应用包内的安装组件；安装结束后会把临时组件移到废纸篓。日常控制继续由 Stats 内嵌的工具完成。新安装时两项规则默认关闭，需用户主动启用；升级会保留原有温度设置。

## 项目文件

- 可运行应用：`运行程序/Stats.app`
- 桌面快捷方式：`~/Desktop/Stats.app`，指向已安装的 `/Applications/Stats.app`，不占用第二份安装。
- 曲线、设置界面和风扇桥接代码：`Modules/Sensors/`
- 风扇控制组件的第三方许可证：`References/MacFanPro/LICENSE`
- 规则说明：`TEMPERATURE-FAN-CURVE.md`

应用包为 Apple Silicon 构建，安装和运行不需要 Xcode。若要从源码重新制作应用，需要用项目附带的本地编译流程重建 Sensors 与 Kit 框架。

## 改造版升级

请用本项目生成的新包升级，避免通过 Stats 官方自动更新覆盖改造功能。本机“检查更新”已设为“从不”；在其他电脑安装后也可到 Stats 通用设置中选择“从不”。
